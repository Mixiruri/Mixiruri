# Hi, I'm Rubia

I make plugins and small mods for the League of Legends client and Discord.

## Projects

| Project | Description |
| --- | --- |
| [RiftTris](https://github.com/Mixiruri/RiftTris) | Tetris inside the League client: 5 modes, 25 achievements, 5 skins and a 90-second Rapid mode built for champ select. |
| [BlackJack-Pengu](https://github.com/Mixiruri/BlackJack-Pengu) | A blackjack game for Pengu Loader, playable in the League client. |
| [Oneko-lol](https://github.com/Mixiruri/Oneko-lol) | A little cat that follows your cursor in the League client. |
| [AnonymousEnemies](https://github.com/Mixiruri/AnonymousEnemies) | Hides enemy champion names in Champion Select. |
| [Mixi-Plugins](https://github.com/Mixiruri/Mixi-Plugins) | A cozy collection of plugins for modified Discord clients. |


## Stack

JavaScript · TypeScript · HTML · Pengu Loader · Discord client mods
